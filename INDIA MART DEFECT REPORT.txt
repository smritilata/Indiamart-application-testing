# DEFECT 001

### Defect ID

IM_DEF_001

### Defect Title

Inconsistent Location Display on Homepage

### Defect Type

Usability Defect

### Severity

Medium

### Priority

Medium

### Steps to Reproduce

1. Open IndiaMART mobile application.
2. Observe the location displayed on the homepage.
3. Click on the location section.

### Expected Result

The selected location should remain consistent throughout the application.

### Actual Result

Homepage displays "Balurghat" while the selected location page displays "Kolkata".

### Status

Open
